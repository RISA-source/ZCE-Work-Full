# What This Is: The First Chapter of a Research Program

**A guide to the ZCE/MDL framework and where it points**  
**Author:** Rishi Saraff | March 2026

---

## The One-Line Summary

**Description length equals learning complexity** — for both classical probability distributions and quantum states, the number of examples (or measurements) needed to learn something equals the number of bits needed to describe it.

$$\boxed{m^*(\rho, \varepsilon) = \Theta\!\left(\frac{K_F(\rho)}{\varepsilon}\right)}$$

This is not a metaphor. It is a proven theorem. And it is the same theorem for both classical and quantum systems.

---

## Why This Is a "First Chapter"

Most theorems are endpoints. You prove a result, it is what it is, you move on.

This one is a starting point. Here is why.

The theorem says: learning complexity = description complexity. That equation connects two things that lived in separate worlds — information theory (description) and statistics (learning) — and says they are measuring the same thing. When two fields are measuring the same thing without knowing it, there is usually a deeper structure underneath that explains why.

What is that structure here? We don't fully know yet. But the theorem points in several directions simultaneously, and each direction leads somewhere new. That is what a "first chapter" means: a result that opens more doors than it closes.

Here are the six doors it opens, in order of concreteness.

---

## Door 1: Quantum Devices Can Be Certified

**The problem.** Building a quantum computer requires checking that each gate works correctly. Standard methods (process tomography) require an exponential number of measurements — literally impossible for systems larger than ~5 qubits.

**What the theorem gives.** The number of measurements needed to certify a quantum gate equals the description length of the *ideal* gate you're checking against. For a CNOT gate: ~150 bits. For any gate built from a small number of stabilizer operations: a few hundred bits. This means roughly 1,000 measurements to certify any standard quantum gate, regardless of the number of qubits in the system.

**Why this matters.** Quantum computers are being built right now. The leading companies (IBM, Google, IonQ, Quantinuum) all face the verification problem. The MDL protocol provides a concrete, computable answer: run $K_F(\text{ideal gate}) \cdot \ln 2 / \varepsilon$ randomized measurements. That's it. The output is both a reconstructed channel AND a certificate of correctness.

**What's new.** The key insight is the distinction between *certification* (verify closeness to a known ideal) and *characterization* (learn the full channel from scratch). Certification is cheap because the ideal has low $K_F$. Standard methods don't make this distinction — they always characterize, which is always expensive.

## Door 2: Quantum Networks Can Be Verified

**The problem.** As quantum networks are built, Alice sends quantum states to Bob over noisy channels. Bob wants to verify he received what Alice sent. Standard QST: exponential measurements. Infeasible.

**What the theorem gives.** Bob needs $K_F(\text{Alice's state})/\varepsilon$ measurements. For structured states (which is what gets sent over useful quantum networks): this is polynomial in the system size. For a 50-qubit entangled state with area-law structure: ~3,000 measurements. For standard QST: ~$10^{33}$.

**Why this matters.** Quantum networks exist only if you can verify quantum information was transmitted correctly. The MDL bound makes this possible for the first time, at scales that matter for real network operation.

## Door 3: Quantum Security Needs a New Criterion

**The current criterion.** Quantum cryptographic security is analyzed using von Neumann entropy $S(\rho)$. High entropy = secure.

**The gap.** A quantum state can have maximum von Neumann entropy ($S = n$) but low $K_F$ — if it is generated by a short quantum circuit. An eavesdropper who knows the circuit structure can learn the state with only $K_F/\varepsilon$ measurements, far fewer than the entropy-based bound suggests. This vulnerability is invisible to entropy-based security analysis.

**What the theorem gives.** The right security criterion is high $K_F$, not high $S$. A quantum key is secure against MDL attacks if $K_F(\text{key}) \geq L$ where $L$ is the adversary's measurement budget times $\varepsilon$.

**Why this matters.** This is a new class of attack — MDL attacks — that standard QKD security proofs don't address. It requires new proofs, new key generation methods (ensure $K_F$ is high, not just $S$), and new security definitions. The gap between $S$ and $K_F$ is real and exploitable.

## Door 4: Quantum ML Has an Occam's Razor

**Classical ML.** The bias-variance tradeoff says: simpler models generalize better. This is formalized by VC dimension, Rademacher complexity, minimum description length regularization. The key insight of classical ML theory is that complexity of the model controls generalization.

**Quantum ML.** No analogous theory existed. Quantum machine learning models prepare quantum states, but there was no "description length" for quantum states that controlled generalization.

**What the theorem gives.** $K_F(\rho)$ is the description length for quantum states. The generalization bound for a quantum ML model with output state $\rho$ is:

$$\text{generalization error} \leq \text{training error} + O\!\left(\sqrt{\frac{K_F(\rho) \ln 2}{m}}\right)$$

Regularize by penalizing $K_F$. This IS the quantum Occam's razor: the simplest quantum state consistent with the training data generalizes best.

**Why this matters.** Quantum ML is an active field with billions in investment and no theoretical foundation comparable to classical ML theory. The MDL framework provides that foundation.

## Door 5: Many-Body Physics Becomes Experimentally Accessible

**The problem.** Ground states of quantum many-body systems encode fundamental physics — superconductivity, magnetism, quantum phase transitions. Learning these states from experiment requires quantum state tomography, which is exponentially expensive.

**What the theorem gives.** Ground states of 1D local Hamiltonians satisfy the area law: entanglement entropy $\leq c \cdot n$. This implies $K_F(\text{ground state}) = O(n \log n)$. Therefore: learning a 1D ground state requires $O(n \log n / \varepsilon)$ measurements. For 100 atoms: ~4,600 measurements. Within reach of current cold atom experiments.

**Why this matters.** Experimentalists have long known that ground states are "structured" and hoped to exploit this. The MDL bound formalizes the hope: area law + MDL = polynomial measurement cost. Ground state tomography is not just theoretically possible; it's *numerically* possible with existing setups.

## Door 6: The Born Rule Is the Efficiency Condition on Nature

This is the deepest door, and the one that takes longest to walk through.

**The question.** Why does quantum mechanics use the Born rule $P = \text{Tr}(\rho \Pi)$? Previous answers: it's the unique consistent rule (Gleason), it follows from symmetry (Zurek's envariance), it's an operational postulate (Masanes et al.), it's a coherence condition for betting (QBism).

**The new answer.** The Born rule is the unique probability assignment for which quantum learning complexity equals description complexity. Any other rule makes quantum learning either harder (more measurements needed) or impossible (some states unlearnable). The Born rule is the *efficiency condition* on nature — the requirement that nature allows itself to be learned at the minimum possible rate.

**Why this matters.** This connects the foundational question "why the Born rule?" to the practical question "how many measurements do you need?" They turn out to have the same answer. The Born rule is not arbitrary — it is the one rule that makes the universe learnable at the rate its description length allows. The efficiency of quantum learning is not a coincidence; it is forced by the Born rule.

**The philosophical claim.** Physical reality is algorithmically compressible. Quantum states that occur in nature have low $K_F$ because they arise from physical processes (Hamiltonians, circuits) that themselves have short descriptions. Laws of physics are minimum-description-length programs for physical reality. Science — the enterprise of finding patterns in nature — is the process of finding short programs for observed data. The success of science is evidence that physical states have low $K_F$. The MDL framework makes this precise.

## What "The Same Theorem" Means

The statement $m^* = \Theta(K/\varepsilon)$ holds for both classical distributions and quantum states with identical structure. This is not analogy. Here is the exact parallel:

| | Classical | Quantum |
|--|-----------|---------|
| Object | Probability distribution $p$ | Density matrix $\rho$ |
| Complexity | Kolmogorov complexity $K(p)$ | ZCE complexity $K_F(\rho)$ |
| Learning task | Learn $p$ from samples | Learn $\rho$ from measurements |
| Distance | Total variation | Trace distance |
| Learning cost | $\Theta(K(p)/\varepsilon)$ | $\Theta(K_F(\rho)/\varepsilon)$ |
| Computability | $K(p)$ uncomputable | $K_F(\rho)$ **computable** |

The quantum result is *stronger* than the classical result: $K_F(\rho)$ is computable (with measured constants $K_F \leq K + 577$ bits), while $K(p)$ is not. The quantum framework gives you the actual number. The classical framework gives you existence.

This means the quantum framework is not a quantum generalization of the classical result — it is a *completion* of it. The classical version told us the bound exists. The quantum version tells us its exact value.

## The Six Open Problems (In Order of Importance)

**1. Tight bounds via Fisher complexity.** The MDL bound $m \leq K_F/\varepsilon$ is tight for incompressible states. For structured states, the tight bound uses Fisher information complexity $I_F(\rho)$ (the number of independent real parameters). Characterize $I_F$ as a computable function of the ZCE program. This closes the gap between the upper and lower bounds.

**2. Efficient algorithm.** The MDL learner is computationally hard in general. The EfficientMDL algorithm (bond-dimension doubling for MPS states) achieves $O(n D^{*4}/\varepsilon^2)$ without knowing $D^*$. Closing the gap to $O(n D^{*2}/\varepsilon)$ requires a realizable MPS learning algorithm.

**3. Quantum PCP connection.** If the quantum PCP theorem is true (approximating ground energies is QMA-hard), then ground state $K_F$ must be large. If the area law is universal, ground state $K_F$ is small. These are complementary. Proving the implication "$K_F$ small $\Rightarrow$ efficient learning" formally connects our framework to quantum complexity theory's biggest open problem.

**4. MDL cryptographic security.** Formalize the MDL attack model. Give security reductions: if $K_F(\text{key}) \geq L$ and the adversary has $m < L/\varepsilon$ measurements, information leakage is bounded. This is a new security proof methodology for QKD.

**5. Thermodynamic cost.** The Landauer principle gives energy cost of erasing $K_F$ bits = $K_F \cdot kT \ln 2$. Learning $\rho$ costs $K_F/\varepsilon$ measurements. Conjecture: thermodynamic cost of quantum state learning = $K_F \cdot kT \ln 2 / \varepsilon$. Proving this requires connecting information-theoretic learning bounds to physical energy bounds — a cross-disciplinary result.

**6. Foundations.** Formalize the claim "physical states have low $K_F$" as a physical axiom. Derive consequences. Prove: this axiom, combined with the Born rule, implies that quantum mechanics is learnable. Conversely, any universe with learnable quantum mechanics must satisfy this axiom. This is the program of algorithmic quantum foundations.
